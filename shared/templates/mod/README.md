# MDS Generic Mod Template

Generic Minecraft Mod development template.

## Project configuration
Select these for each project:
- Minecraft version
- Mod loader
- Loader version
- Java version
- Build system
- Required dependencies

## Supported loader candidates
- Fabric
- Forge
- NeoForge

## Development rules
- Never assume a default Minecraft version.
- Verify official loader documentation.
- Select compatible dependencies.
- Generate build files for the selected environment.
- Run build and runtime tests before release.
