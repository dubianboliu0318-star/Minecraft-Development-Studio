# MDS Generic Datapack Template

Minecraft Java Edition datapack source template.

## Version policy
- No Minecraft version is fixed.
- Select the target version for each project.
- Verify the official datapack format for that version.
- Generate pack.mcmeta for the selected version.
- Adjust directory naming and file structure when required.

## Structure
- data/example/functions: Example functions
- Project configuration: project-config.example.json

## Before release
- Set the target Minecraft version.
- Set the correct pack metadata.
- Confirm namespace and directory conventions.
- Validate JSON and function syntax.
- Test in the target Minecraft version.
